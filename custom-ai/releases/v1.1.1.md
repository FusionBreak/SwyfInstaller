Fixes an issue introduced by recent game updates where callers would greet you, then repeat **“Sorry, what were you saying?”** after your reply.

## What's changed

- Fixed conversations failing after the caller's opening message.
- Improved compatibility with changes to the game's AI response format.
- **Test Connection** now checks the response format used by your installed game.
- Added clearer error messages for network connection problems.

Your saved provider settings, ManifestDeX sign-in and game backups are preserved when updating.

## How to update

1. Close the game and the AI Settings panel.
2. Open **SwyfInstaller**, click **Update**, and let it apply the mod.
3. Launch the game and press **F8** to check your settings.

**Already using SwyfInstaller?** You only need to update the mod. The current installer app supports this release.

**Manual installation:** Extract the complete ZIP into the game folder and run **Install Custom AI.cmd**.

Tested with **Scam With Your Friends Playtest build 25909758**. After future Steam updates, use **Play with Custom AI.cmd** to reapply compatible patches. Major game changes may still require a new mod version.
