Fixes callers falling back to “Sorry, what were you saying?” after recent game updates. Verified in Scam With Your Friends Playtest build **25909758**, including three consecutive successful caller replies.

## Fixes and improvements

- Custom providers use the game's shipped prompt preparation path. Prompt/version lookups are no longer mistaken for model completion requests. Disabling custom AI preserves the original game route.
- **Test Connection** reads the installed game's dialogue schema, including newly required fields such as `comedy`, and checks the returned response against it.
- The ManifestDeX AI service now accepts bounded additions to caller schemas while validating replies against the complete game schema. This service update is already live.
- Network failures distinguish connection, DNS, TLS and timeout errors instead of showing one generic message.
- Installation verifies the new prompt hook and preserves existing provider settings, account connections and game backups.

## Update

Close the game and AI Settings panel, then press **Update** in SwyfInstaller and allow it to apply the mod. The existing installer app supports this release; no new installer app is required.

For manual installation, extract the entire ZIP into the game folder and run **Install Custom AI.cmd**. After a future Steam update, **Play with Custom AI.cmd** can reapply compatible patches before launch.

Requires Windows x64, a compatible Mono Playtest build, .NET Runtime 10 and ASP.NET Core Runtime 10. The included prerequisite setup checks for missing runtimes. Only the lobby host needs the mod. Speech recognition and synthesis remain handled by the game.

Small caller schema additions are now supported within validation limits. Changes to core game APIs or protocols can still require a mod update. This release does not change VPN or firewall settings.

Validation: 98 mod checks, two compiled bridge routing checks, sign-in UI tests, and live multi-turn gameplay. Server validation: 58 schema checks, 137 integration checks, and 76 deployment probes with zero failures. No game binaries, API keys, account sessions or conversation logs are included.
