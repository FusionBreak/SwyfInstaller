Fixes callers repeating **“Sorry, what were you saying?”** after your reply on recent game builds, even when Test Connection succeeds.

## What's changed

- Restored compatibility with game updates that omit the optional dialogue response format.
- The mod now uses the game's installed alternative schema when needed, preserving your conversation history and any response format the game already supplies.
- **Test Connection** uses the same schema lookup as actual conversations.

Your saved provider settings, ManifestDeX sign-in and game backups are preserved when updating.

## How to update

1. Close the game and the AI Settings panel.
2. Open **SwyfInstaller**, click **Update**, and let it apply the mod.
3. Launch the game and press **F8** to check your settings.

The current installer app supports this release; you only need to update the mod.

**Manual installation:** Extract the complete ZIP into the game folder and run **Install Custom AI.cmd**.

Tested with **Scam With Your Friends Playtest build 25943600**, including a successful in-game conversation. Major game changes may still require another mod update.
