Updates the mod package for the **Scam With Your Friends full release**, Steam app **4954910**, build **25965579**.

## What's changed

- Builds the game bridge against the full release's assemblies.
- Keeps the dialogue compatibility fixes from v1.1.2: when the game omits its optional response format, the mod uses the installed official dialogue schema. Test Connection uses the same schema lookup.
- Includes updated installation instructions for the full release.

## How to update

1. Close the game and the AI Settings panel.
2. Update **SwyfInstaller to v1.1.5** so it automatically selects the full release's folder.
3. Press **Install**, then launch the game and open **F8** to check your settings.

**Manual installation:** Extract the complete ZIP into the full release's game folder and run **Install Custom AI.cmd**.

Settings, sign-in and backups already in that folder are preserved. Playtest settings are not automatically copied into the full release.

Major game API changes may still require another mod update.
