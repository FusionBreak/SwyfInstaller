Adds an optional **custom voice**: any OpenAI-compatible text-to-speech provider can replace the game's built-in caller voices.

## What's changed

- New **Use a custom text-to-speech provider** card in AI Settings with **TTS API Base URL**, **TTS model ID**, **Default voice**, an optional **TTS API key** (blank preserves the saved key, **Delete saved API key** removes it), optional **Speech speed**, and a **Per-caller voice mapping** from each game voice path to a provider voice.
- **Test Voice** speaks a sample with the current form values without saving anything.
- Speech is synthesized only on the computer that speaks the line. Every listener in the call — including unmodded guests — hears it through the game's own voice relay. Calls played on another player's computer keep that machine's built-in voice, and filler words always stay vanilla.
- On any provider failure the game's built-in voice speaks the line instead. Long lines carry extra delay because each utterance is synthesized in full before playback starts.
- Installation now writes hook manifest **v9** with two additional voice gates (`PocketTtsSingleton.Speak` and `SpeakTracked`). Contract probes verify the game's voice entries and abort before writing any file when they have changed; an earlier v8 installation upgrades to v9 automatically on the next repair install.

Your saved provider settings, ManifestDeX sign-in and game backups are preserved when updating. The custom voice stays off until you enable it and click **Save Settings**.

## How to update

1. Close the game and the AI Settings panel.
2. Open **SwyfInstaller**, click **Update**, and let it apply the mod.
3. Launch the game, press **F8**, tick **Use a custom text-to-speech provider**, fill in the TTS fields, and click **Save Settings**.

The current installer app supports this release; you only need to update the mod.

**Manual installation:** Extract the complete ZIP into the game folder and run **Install Custom AI.cmd**.

Major game changes to the caller voice pipeline may require another mod update; in that case the installer stops with a compatibility error before modifying any game file.
