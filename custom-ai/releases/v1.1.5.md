Fixes the launch failure after the latest game update, where the installer stopped with `Incompatible game libraries: System.String System.Uri::EscapeDataString(System.String)`.

The game's `System.dll` no longer provides `Uri.EscapeDataString`. The bridge used it to encode the one-time token when opening the settings panel (F8). It now uses its own RFC 3986 percent-encoder, so the generated link is unchanged and the compatibility check passes again.

Every other member the bridge references was re-verified against the updated game libraries.

Close the game, extract the complete ZIP into its folder, and run **Install Custom AI.cmd**. Existing settings, sign-in sessions, and original-assembly backups are preserved.
